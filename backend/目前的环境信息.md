# 服务器配置4核8G
# 已安装Mysql 8.0（部署在podman内）
# Redis 7.2已安装（podman内），并且已经开启混合持久化
# nginx已安装（podman内）


❌ 绝对不进 Redis 的数据（冷数据/持久化数据）：

用户密码、邮箱等敏感或低频数据： 用户登录后，只查一次 MySQL。

已完成/已取消的面试会话 (Interview Sessions)： 历史订单不需要占内存。

完整的全量对话记录 (Interview Dialogues)： 面试结束后的录音和文字直接落库 MySQL，Redis 里立刻删掉。

✅ 必须进 Redis 的数据（热数据/状态数据）：

1.活跃用户的 Token/Session ID：

缓存什么： String (Key: token_uuid, Value: user_id)，设置 2 小时过期。网关每次请求都要校验这个 Token。

2.高频查询的岗位：

缓存什么： 如果某个“Go初级开发工程师”岗位有 100 个人同时面，把它的描述缓存为 String，避免并发打穿 MySQL。

3.正在进行中的面试上下文（最核心！）
